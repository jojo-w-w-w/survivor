# Roguelike Survivor

## 项目简介

- 这是一个简单的肉鸽游戏，用来写进简历里和提升工程化的能力


## 已实现功能

- 菜单、游玩、暂停和死亡状态
- 玩家移动与射击
- 多种敌人及随机生成
- 碰撞检测
- 经验与升级系统
- 多重射击等强化选项

## 技术栈

- C++17
- SFML 3
- CMake
- Linux

## 操作方式

- W/A/S/D：移动
- J：向最近的敌人射击
- Esc：暂停
- 数字键 1/2/3：选择升级
- 鼠标左键：操作菜单

## 构建与运行

### 依赖

- 支持 C++17 的编译器
- CMake 3.14 或更高版本
- SFML 3

### 编译

```bash
cmake -S . -B build
cmake --build build -j
```

### 运行

```bash
./build/survivor
```

## 项目结构

- include        作用是用来存放每种文件的头文件，这样无论是通过 cmake 进行编译还是自己查找文件都很方便
- source         用来存放每种文件的源文件，其本身的目的和 include 中是相同的
- assets         作用是存放一些图片资源，用来加载人物，敌人以及背景图
- MenuState      菜单状态，也就是游戏的主界面
- PlayingState   游玩状态，也就是游玩时所需要处理的东西
- UpgradingState 更新状态，当经验值可以升级时使用
- PauseState     暂停状态，一个单机肉鸽游戏怎么能没有暂停？
- DeadState      死亡状态，很不幸你输了

### 核心设计

引入状态机后在游玩游戏的时候不同的界面在写程序的时候就是不同的状态

- GameState 抽象设计的游戏状态基类，包含每个状态中应该有的基本功能：时间处理、逻辑处理、渲染
- StateStack 顾名思义状态栈就是存放状态的栈，某些状态不是完全的切换关系，而是暂时的置于上层。比如在游玩时想要暂停。
- GameContext
- EnemyBase
- EnemyFactory
- ResourceManager
