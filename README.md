# Roguelike Survivor

## 项目简介

- 这是一款基于 C++17 和 SFML 3 开发的 2D Roguelike 生存游戏。玩家需要躲避持续生成的敌人，通过射击获取经验，并选择随机升级强化角色能力。


## 已实现功能

- 菜单、游玩、暂停和死亡状态
- 玩家移动与射击
- 多种敌人及随机生成
- 碰撞检测
- 经验与升级系统
- 多重射击等强化选项

## 技术栈

- C++17
- SFML 3
- CMake
- Linux

## 操作方式

- W/A/S/D：移动
- J：向最近的敌人射击
- Esc：暂停
- 数字键 1/2/3：选择升级
- 鼠标左键：操作菜单

## 构建与运行

### 依赖

- 支持 C++17 的编译器
- CMake 3.14 或更高版本
- SFML 3

### 编译

```bash
cmake -S . -B build
cmake --build build -j
```

### 运行

```bash
./build/survivor
```

## 项目结构

- `include/`：存放类和接口的声明
- `source/`：存放具体功能实现
- `assets/`：存放角色、敌人和背景等图片资源
- `MenuState`：主菜单状态
- `PlayingState`：游戏核心逻辑状态
- `UpgradingState`：角色升级选择状态
- `PauseState`：暂停状态
- `DeadState`：玩家死亡后的结算状态

### 核心设计

引入状态机后在游玩游戏的时候不同的界面在写程序的时候就是不同的状态

- `GameState`：所有游戏状态的抽象基类，统一定义输入事件处理、逻辑更新和画面渲染接口。
- `StateStack`：负责持有和切换游戏状态，支持状态的压入、弹出和替换。可能销毁当前状态的操作会延迟到当前成员函数执行结束后处理，避免状态在执行过程中被释放。
- `GameContext`：主要功能是集中管理全局的容器，把游戏当前运行所需的对象集中在一起。同时使用智能指针管理玩家等对象资源
- `EnemyBase`：抽象出来的敌人的基本状态属性
- `EnemyFactory`：使用工厂的设计模式来生产三种不同的敌人，核心还是对敌人种类的抽象
- `ResourceManager`：使用 `shared_ptr` 和 `weak_ptr` 缓存纹理资源，避免相同图片被重复加载，并在资源不再使用时自动释放。
